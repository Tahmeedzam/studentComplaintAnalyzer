How The System Works

A streamlined 4-step pipeline transforming student text into structured, actionable administration tickets.

1. Submit Grievance

Students submit complaint titles and descriptions via the intuitive portal.

2. NLP & ML Pipeline

Text is cleaned, lemmatized, vectorised via TF-IDF, and classified into 12 categories.

3. Smart Triage

VADER analyzes sentiment and priority heuristics automatically assign High, Medium, or Low priority.

4. Action & Resolution

Administrators track status, respond to students, and view real-time department analytics.

NLP Technical Architecture
  • • Text Cleaning: Lowercasing, URL/Regex filtering, Tokenization
  • • Feature Extraction: WordNet Lemmatization + TF-IDF (1-2 N-grams)
  • • Classification: Multinomial Logistic Regression / Linear SVM
  • • Sentiment: NLTK VADER Intensity Scoring (-1.0 to +1.0)
  • • Storage: SQLAlchemy ORM (SQLite / PostgreSQL)
